# Knowledge Base

このディレクトリはAIが毎回作業前に読む知識ベースである。

新しい知見が得られたらここへ追記する。

## 管理する内容

- [Coding Rules](coding-rules.md): 実装時に守るルール
- [Lessons Learned](lessons-learned.md): 問題、原因、対応、再発防止
- [Anti Patterns](anti-patterns.md): 避けるべき実装・運用と代替案

一時的な作業ログ、Secret、接続情報は記録しない。現在の設計は[`docs/architecture/`](../architecture/README.md)、設計判断は[`docs/decisions/`](../decisions/README.md)、運用手順は[`docs/runbooks/`](../runbooks/README.md)で管理する。
